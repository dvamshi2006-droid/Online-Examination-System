# Online-Examination-System
The Online Examination System is a Java Full Stack web application for conducting online exams securely and efficiently. Students can register, attend exams, submit answers, and view results. Admins can manage exams, questions, students, and results. It uses HTML, CSS, JavaScript, Spring Boot, REST APIs, and MySQL.
